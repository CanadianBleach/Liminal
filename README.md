# Liminal

A fast-paced wave survival FPS built with Three.js and Rapier physics.

## Overview

Liminal is a browser-based first person shooter focused on surviving increasingly difficult enemy waves in a surreal liminal-style environment. The game combines responsive movement, physics-driven gameplay, and arcade-inspired combat using modern web technologies.

## Live Demo

Play here:

[https://liminal-nine.vercel.app/](https://liminal-nine.vercel.app/)

## Features

* Wave-based survival gameplay
* First person shooter mechanics
* Physics powered by Rapier
* Rendering with Three.js
* Browser-playable with no install required
* Responsive movement and combat systems
* Backrooms inspired atmosphere and environments

## Tech Stack

* Three.js
* Rapier Physics
* JavaScript
* Vite
* WebGL

## Goals of the Project

This project was built to explore:

* Real time 3D game development on the web
* Physics simulation in browser environments
* FPS gameplay systems
* Performance optimization with Three.js
* Interactive gameplay experiences using modern JavaScript tools
